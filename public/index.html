Ventas por Línea de Pedido
Una fila por producto vendido. Incluye fecha, cliente, zona, categoría, cantidad, precio, descuento, estado de pago y despacho. Ideal para forecasting de ventas.
✓ Columna objetivo: cantidad o subtotal_linea
✓ Variables: fecha, zona, cliente_tipo, categoria_producto
✓ Uso: Predicción de demanda por producto
👥
Análisis de Clientes
Una fila por cliente con historial completo: pedidos, monto acumulado, ticket promedio, días sin comprar, facturas en mora. Ideal para segmentación y churn.
✓ Columna objetivo: dias_sin_comprar o facturas_en_mora
✓ Variables: tipo, zona, monto_total, ticket_promedio
✓ Uso: Predecir riesgo de abandono o mora
📦
Rendimiento de Productos
Una fila por producto con stock, margen, unidades vendidas (30 y 90 días), descuento promedio y valor de inventario. Ideal para optimización de catálogo.
✓ Columna objetivo: unidades_ultimos_30d
✓ Variables: categoria, precio, margen, stock
✓ Uso: Predecir demanda y optimizar precios
💳
Cobranza y Riesgo de Pago
Una fila por factura con estado, días de mora, % cobrado, historial de pagos. Ideal para modelo de riesgo crediticio.
✓ Columna objetivo: dias_mora o estado
✓ Variables: tipo_cliente, zona, monto_total, dias_credito
✓ Uso: Predecir probabilidad de mora
🏭
Inventario Materia Prima
Stock actual vs. mínimos, cobertura en días, valor de inventario por material. Ideal para alertas automáticas de reposición.
✓ Columna objetivo: estado_stock o cobertura_dias
✓ Variables: stock_actual, consumo_mensual, stock_minimo
✓ Uso: Predecir cuándo reabastecer
