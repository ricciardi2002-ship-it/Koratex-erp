¿Qué es el sistema ERP de Koratex?

Introducción y panorama general

Un ERP (Enterprise Resource Planning) es un sistema de gestión que centraliza todas las operaciones de una empresa en un solo lugar. En el caso de Koratex, este sistema permite gestionar pedidos, clientes, inventario, finanzas y logística desde cualquier dispositivo con internet.

✅ Lo más importante que debes saber

  • Solo necesitas un navegador web (Chrome, Safari, Firefox) para usarlo.
  • No hay que instalar ningún programa en tu computadora o celular.
  • Todos los datos se guardan en la nube — no se pierden aunque cierres el navegador.
  • Varios usuarios pueden usarlo al mismo tiempo desde distintos dispositivos.
  • Cualquier acción (un pedido, un pago) se actualiza automáticamente para todos.

¿Cómo funciona técnicamente? (sin tecnicismos)

Imagina tres "lugares" distintos que trabajan juntos:

🖥️

La pantalla (Frontend)

Lo que ves en el navegador. El formulario de login, los módulos, los botones. Es un archivo HTML.

⚙️

El servidor (Backend)

Un programa en Railway que recibe los datos y los procesa. Ej: valida contraseñas, calcula totales.

🗄️

La base de datos (DB)

Donde se guardan todos los datos permanentemente: clientes, pedidos, pagos. Está en Supabase.

Exportar datos a Excel

Dos métodos para analizar tus datos en Excel

Método 1 — Exportar CSV desde Supabase (más fácil)

  1. Entra a Supabase → Table Editor

    Abre supabase.com y ve al proyecto Koratex.

  2. Selecciona la tabla que quieres exportar

    Por ejemplo: "pedidos", "clientes" o "facturas".

El servidor · Railway

Configuración, variables de entorno y deploys

Railway es la plataforma que ejecuta el código del servidor. Aquí es donde se configuran las contraseñas, puertos y conexiones — es como el "panel de control" del motor del ERP.

Variables de entorno (configuración del servidor)

Las variables de entorno son como "contraseñas y configuraciones" que el servidor necesita para funcionar. Se configuran en: Railway → servicio Koratex-erp → Variables

# Variables actuales en Railway DATABASE_URL = postgresql://postgres:koratex2001*@db.pxmiqsoniaighcekdvyq.supabase.co:5432/postgres JWT_SECRET = koratex_jwt_secret_2025 (clave para cifrar tokens de sesión — no cambiar) PORT = 3000 (puerto del servidor — Railway lo asigna automáticamente) NODE_ENV = production
⚠️
Si cambias la contraseña de Supabase Debes actualizar la variable DATABASE_URL en Railway con la nueva contraseña. De lo contrario el servidor no podrá conectarse a la base de datos y el ERP dejará de funcionar.

Cómo actualizar una variable en Railway

  1. Entra a railway.app y haz login

    Usa la cuenta con la que creaste el proyecto.

  2. Abre el proyecto "Koratex-erp"

    Haz clic en el servicio principal (no en la base de datos de Railway si la hay).

  3. Ve a la pestaña "Variables"

    Aquí verás todas las variables configuradas.

  4. Haz clic en la variable que quieres cambiar

    Edita el valor y haz clic en "Save". Railway reiniciará el servidor automáticamente.

Guía de uso diario

Paso a paso para las operaciones más comunes

📦 Cómo registrar un nuevo pedido

  1. Entra con el usuario Comercial o Admin

    comercial@koratex.com / koratex2025

  2. Ve al módulo "Nuevo Pedido" en el menú lateral

    Ícono de carrito en la barra de navegación.

  3. Selecciona el cliente en el desplegable

    El sistema aplica automáticamente la lista de precios según el tipo de cliente (Oro/Plata/Bronce).

  4. Agrega los productos

    Selecciona el producto, ingresa la cantidad. Puedes agregar hasta 15 líneas por pedido.

  5. Revisa el total y haz clic en "Confirmar Pedido"

    El pedido se guarda en la base de datos y aparece en la Cola de Pedidos para todos los usuarios.

🚚 Cómo actualizar el estado de un pedido

  1. Ve al módulo "Cola de Pedidos"

    Verás todos los pedidos con su estado actual.

  2. Encuentra el pedido y haz clic en "Cambiar Estado"

    Los estados van en orden: Pendiente → Preparación → Despachado → Entregado

  3. El estado se actualiza en tiempo real

    Todos los usuarios verán el nuevo estado inmediatamente (el sistema refresca cada 60 segundos automáticamente).

💰 Cómo registrar un pago

  1. Entra con el usuario Finanzas o Admin

    finanzas@koratex.com / koratex2025

  2. Ve al módulo "Cobranza"

    Verás todas las facturas pendientes con monto y días de mora.

  3. Selecciona la factura, ingresa el monto y el tipo de pago

    Tipos: Efectivo, Transferencia, Cheque.

  4. Haz clic en "Registrar Pago"

    El pago queda registrado y el estado de la factura se actualiza automáticamente.

📊 Actualización automática de datos

El sistema recarga automáticamente los datos cada 60 segundos. Esto significa que si alguien registra un pedido desde otro dispositivo, tú lo verás en tu pantalla en menos de un minuto sin necesidad de recargar la página.

También puedes forzar la actualización cambiando de módulo en el menú lateral.

Configurar todo desde cero

Guía completa de instalación para un nuevo entorno

ℹ️
¿Cuándo usar esta sección? Solo si el sistema falla completamente y necesitas volver a montarlo desde cero, o si quieres crear una copia del sistema para otra empresa/entorno.

Paso A — Crear la base de datos en Supabase

  1. Crea una cuenta gratuita en supabase.com

    Haz clic en "Start for free" y regístrate con un email.

  2. Crea un nuevo proyecto

    Dale un nombre (ej: "koratex-erp"), elige una región cercana (South America) y anota la contraseña de la base de datos.

  3. Ve a SQL Editor → New query

    En el menú izquierdo de Supabase.

  4. Ejecuta el script supabase-schema.sql

    Abre github.com/ricciardi2002-ship-it/Koratex-erp → archivo supabase-schema.sql → botón "Raw" → Ctrl+A → Ctrl+C → pégalo en el SQL Editor → "Run".

  5. Copia la cadena de conexión

    En Supabase: Settings → Database → Connection string → URI. Tendrá este formato:

postgresql://postgres:[TU-CONTRASEÑA]@db.[TU-ID-PROYECTO].supabase.co:5432/postgres

Paso B — Configurar Railway

  1. Crea una cuenta en railway.app

    Puedes registrarte con tu cuenta de GitHub para conectarlos automáticamente.

  2. Crea un nuevo proyecto desde GitHub

    New Project → Deploy from GitHub repo → selecciona "Koratex-erp".

  3. Agrega las variables de entorno

    Ve a Variables y agrega:

DATABASE_URL = postgresql://postgres:[CONTRASEÑA]@db.[ID].supabase.co:5432/postgres JWT_SECRET = koratex_jwt_secret_2025 NODE_ENV = production
  1. Railway desplegará el servidor automáticamente

    En 2-3 minutos el sistema estará disponible en la URL que Railway te asigne.

✅
¡Listo! El sistema ya está funcionando Abre la URL de Railway en el navegador. Deberías ver la pantalla de login de Koratex ERP. Usa admin@koratex.com / koratex2025 para entrar.

¿Qué hacer si algo falla?

Diagnóstico y solución de los problemas más comunes

❌ No puedo entrar al sistema (página no carga)

Causa probable: El servidor en Railway está caído o reiniciándose.

  • Espera 2-3 minutos y recarga la página.
  • Entra a railway.app → proyecto Koratex → verifica que el servicio esté "Active" (punto verde).
  • Si está en rojo, haz clic en el servicio → "Restart".

❌ Login dice "Error de conexión con el servidor"

Causa probable: El servidor no puede conectarse a la base de datos.

  • Verifica que la variable DATABASE_URL en Railway sea correcta.
  • Verifica que Supabase esté activo (supabase.com → tu proyecto → debe mostrar "Healthy").
  • Si la contraseña de Supabase fue cambiada, actualiza DATABASE_URL en Railway.

❌ Login dice "Credenciales inválidas"

Causa probable: Email o contraseña incorrectos, o el usuario no existe en la base de datos.

  • Verifica que el email sea exactamente: admin@koratex.com (sin espacios).
  • Contraseña: koratex2025 (sin espacios, minúsculas).
  • En Supabase → Table Editor → tabla usuarios → verifica que el usuario exista y que activo = true.

⚠️ Los datos no se actualizan / están desactualizados

Causa probable: Cache del navegador o el refresco automático no ha corrido aún.

  • Cambia de módulo y regresa (el sistema recarga los datos al navegar).
  • O espera hasta 60 segundos (el sistema refresca automáticamente).
  • Última opción: Ctrl+F5 (recarga forzada del navegador).

⚠️ Supabase deja de ser gratuito (plan free lleno)

Límite del plan gratuito: 500 MB de base de datos.

  • En Supabase → Settings → Usage → verifica el espacio usado.
  • Si se acerca al límite, puedes limpiar el audit_log (tabla de historial) que crece rápido.
  • O actualiza al plan Pro de Supabase (~$25 USD/mes) para más capacidad.
